# Velour — où coller ces textes (guide en français)

Les titres ## mélangent parfois anglais et allemand selon les consoles ; les lignes *italiques* indiquent où coller, en français.

Les textes à publier sont en texte plat (sans `**` Markdown) pour un copier-coller direct vers Apple et Google.

Locale pour ce fichier : App Store Connect → Deutsch (Deutschland) · Play Console → allemand (Allemagne) (libellés exacts selon ta console).

### App Store Connect

1. [App Store Connect](https://appstoreconnect.apple.com) → Mes apps → Velour → App Store → version iOS → localisation = celle indiquée ci‑dessus.
2. Repère les champs Name, Subtitle, Keywords, Promotional Text, Description, What’s New in This Version (interface souvent en anglais même pour une fiche DE).
3. Promotional Text : mise à jour possible sans nouvelle build selon les règles Apple du moment.
4. What’s New in This Version : obligatoire par langue — voir section dédiée plus bas (adapter à chaque release ; réf. dépôt : 1.2.3+21).

### Google Play Console

1. [Play Console](https://play.google.com/console) → Velour → Présence sur le Play Store → Fiches principales du store → langue allemand → Titre, Courte description, Description complète.
2. Lors d’un déploiement de version (AAB) : étape Release notes / notes de version par langue — voir section en fin de fichier.

## Beschreibung (4000 max)

*Champ Description (ou Beschreibung).*

Du siehst das Rack. Die Uhr verhandelt nicht. Velour ist ein anspruchsvolles Neon-Puzzle aus Runs: jede Platzierung ist Logik unter Druck—Form- und Farb-Clears plus das Perfekt (drei identische Gems), das den Score sprengt und Heat speist für Bonus‑LUX und clutch Zeitretter. Für alle, die schneller denken wollen als die Zeit nachgibt.

Warum „noch eine Runde“
• Challenge zuerst: schnell Muster lesen—nicht den „billigen“ Drilling nehmen, wenn Perfekt eine Gem entfernt ist.  
• Look, der spielbar bleibt: dark‑matte Neon, klare Lesbarkeit, respektiert „Bewegung reduzieren“.  
• Beweis global: Weltrangliste für deinen besten Run + Oracle-Name, wenn die App fragt.

Modi nach Mut
• Klassik zum sauberen Training.  
• High Stakes / Royal, wenn Einsatz, Ziele und Rewards steigen.

Meta
LUX im Shop für Skins und Session-Boosts (Regeln in-app). Täglicher LUX-Bonus auf dem Homescreen, wenn berechtigt.

Vertrauen
Store-Builds können Analytics/Crash Reporting nutzen—siehe verlinkte Datenschutzerklärung.

Hol dir Velour, wenn du Logik unter Zeitdruck, neon‑klare Optik und eine Weltrangliste willst—und dann liefere eine Run, die zählt.
